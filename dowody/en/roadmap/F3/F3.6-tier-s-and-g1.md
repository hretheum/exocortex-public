# F3.6. Quick test and gate G1

[← F3](../F3-first-pass.md)

> **Status: to do** · as of 30 September 2026
>
> All dependencies are done (F3.4, F3.5, F2.9 and F2.10), so the task can be started. Formally it is still "to do", but its first step began on the server on 30 September: the first extraction run on the tuning sample (20 documents) is in progress. Blind rating has not started, and there is no G1 decision. As planned, the control set will be opened only after the tuning sample has been rated.

## In brief

This is the first real measurement. We run both variants of the program on 20 documents, and a person rates all the extracted claims blind. The result closes with gate G1, a written decision on whether to move on to the larger pilot.

## Why

The pilot costs about a week of work, so we first check with a cheap test whether the effect exists at all. If adding the mode field changes nothing already on 20 documents, the pilot would be a waste of time and it is better to describe that result in the report straight away. The test also shows whether the whole chain (running, blind rating, storing results) works on real data, and not only on a trial experiment.

## What to do

1. Run both extractor variants on the tuning sample (20 documents), with one local model.
2. Rate blind (in the owner's interface from F2.10) all claims from the tuning sample (with 20 documents this is usually several dozen to over a hundred claims).
3. Only then run both variants on the control set and rate its claims. The control set is opened once.
4. Compare the results with the thresholds in the card. Write the G1 decision in both languages, with links to the results in the tables.
5. Approve the decision.

## Done when

The G1 decision is published, points to the results it rests on, and the F2.5 processor accepted it without objections.
