# F3.6. Quick test and gate G1

[← F3](../F3-first-pass.md)

## Why

A cheap check of whether the effect exists at all, before we spend a week on a pilot.

## What to do

1. Run both extractor variants on the tuning sample (20 documents), with one local model.
2. Rate blind (in the owner's interface from F2.10) all claims from the tuning sample (with 20 documents this is usually several dozen to over a hundred claims).
3. Only then run both variants on the control set and rate its claims. The control set is opened once.
4. Compare the results with the thresholds in the card. Write the G1 decision in both languages, with links to the results in the tables.
5. Approve the decision.

## Done when

The G1 decision is published, points to the results it rests on, and the F2.5 processor accepted it without objections.
