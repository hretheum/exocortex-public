# F2.2. Allowlist of sources

[← F2](../F2-lab.md)

> **Status: done** · as of September 30, 2026

The lab's entry point refuses with code 403 any type and address not on the list, adapters that download from the web check the domain before downloading, and every refusal goes to the log as an entry without content. ## In short

This task creates an explicit list of the places the lab may take material from. Everything outside the list is refused, and every refusal is written to the log.

## Why

The lab is public and meant to be checkable, so it must be clear where its material comes from. If it accepted everything, a private note, an email or a text that must not be used could end up in the results, and one mistake would be enough. The list turns this into a rule: a new source appears only through a change to a file with a stated reason, which anyone can see in the history of the repository.

## What to do

1. A file `lab/sources.yaml` in the repository: for each source, its type, address or address pattern, licence or basis for use, and the person who added it.
2. The lab Capture API (its entry point for loading documents) rejects any `source_type` not on the list. Adapters that fetch from the web check the address domain against the list before fetching.
3. The `dowody/` folder is allowed from the start. External sources are added in F3 and F5.
4. Test: an attempt to send content with a disallowed type, and an attempt to fetch from a disallowed domain, both end in a refusal and a log entry.

## Done when

The list is public in the repository, both test cases end in a refusal, and adding a source requires a commit with a reason.
