# F2.8. Raw results export

[← F2](../F2-lab.md)

## Why

The dossier shows conclusions. For an outsider to check them, they need the data the conclusions were computed from and a way to compute them again.

## What to do

1. For each experiment a folder `dowody/data/<slug>/` with CSV files: configurations, sample manifest (document ids and checksums, seeds), results, ratings (raters under pseudonyms).
2. A data description in Frictionless Data format (`datapackage.json`): columns, types, units.
3. A script in the repository that computes the numbers shown in the dossier from the CSV files alone, including confidence intervals.
4. The export runs after every experiment run and goes to the repository through the publisher.

## Done when

For the toy experiment, the script run on a fresh clone of the repository gives the same numbers as the dossier.

## Progress

- 2026-09-29: the lab exports the data of every experiment with runs to `data/<slug>/`: configurations, samples with seeds and checksums, runs, results, claims, the numbers of the pages under their ids and ratings under pseudonyms, with the columns described in `datapackage.json` (Frictionless Data).
