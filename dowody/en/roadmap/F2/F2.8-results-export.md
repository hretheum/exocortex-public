## In brief

This task makes the raw data of every experiment available in plain table files, together with a script that computes the results again from those files. That way anyone can check whether the numbers on an experiment's page agree with the data.

## Why

A page with conclusions says what came out, but the reader has to take its word for it. For an outsider to check it, they need the data the results were computed from and a way to compute them again. Example: a researcher downloads the repository, runs one script and sees the same numbers that are in the experiment's write-up. When they agree, the result can be considered checked, and when they do not, it is clear where to look for the error.

## What to do

1. For each experiment a folder `dowody/data/<slug>/` with CSV files: configurations, sample list (document ids and checksums, sampling seeds), results, ratings (raters under pseudonyms).
2. A data description in Frictionless Data format (an open standard for describing datasets, file `datapackage.json`): columns, types, units.
3. A script in the repository that computes the numbers shown in the dossier from the CSV files alone, including confidence intervals (ranges in which the true value probably lies).
4. The export runs after every experiment run and goes to the repository through the publisher (the program that every fifteen minutes moves checked documents to the repository).
