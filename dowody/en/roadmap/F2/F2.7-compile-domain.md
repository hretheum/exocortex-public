# F2.7. Result pages and roadmap state

[← F2](../F2-lab.md)

## Why

Someone opening the repository should not have to read tables or JSON files to understand what is going on. We need pages assembled from the graph: the roadmap state, the list of experiments, a dossier for each experiment.

## What to do

1. A `dowody` compile domain in the lab. Hook it into `wiki_compiler.compile_all`, because that is the only dispatcher the deployed units run.
2. Pages: roadmap state (from task file headers: phase, status, dependencies, blocked tasks), list of experiments with their state, experiment dossier (card versions, configurations, runs, results with confidence intervals, gate decisions, links to raw data).
3. Fixed page text in both languages from templates, numbers and names from the graph. Polish and English pages are produced in the same run.
4. Pages go to `dowody/pl/generated/` and `dowody/en/generated/` in the working copy of the repository and pass the same checks as everything else.

## Done when

The roadmap state page shows every task with its current status. The toy experiment has a dossier in both languages. The parity check passes on the generated pages.
