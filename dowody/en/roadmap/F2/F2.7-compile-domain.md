## In brief

This task makes the lab assemble readable pages by itself: the state of the work plan, the list of experiments and a separate page describing each of them. The pages are produced in Polish and in English from data stored in the database, so nobody retypes them by hand.

## Why

Someone opening the repository wants to see what is done and what we are studying, not read database tables or raw JSON files. Hand-written summaries would soon drift away from reality, so the pages are built from the same data the lab works on. Example: the roadmap state page shows for each task whether it is done and what it waits for, and when the status in the task file's header changes, the page changes with it.

## What to do

1. A `dowody` compile domain in the lab, that is, a set of rules that builds pages from the data in the lab database. Hook it into `wiki_compiler.compile_all`, because that is the only entry point the jobs running on the server call.
2. Pages: roadmap state (from task file headers: phase, status, dependencies, blocked tasks), list of experiments with their state, experiment dossier (card versions, configurations, runs, results with confidence intervals, gate decisions, links to raw data). A confidence interval is a range in which the true value very probably lies.
3. Fixed page text in both languages from templates, numbers and names from the lab database. Polish and English pages are produced in the same run.
4. Pages go to `dowody/pl/generated/` and `dowody/en/generated/` in the working copy of the repository and pass the same checks as everything else.

## Done when

The roadmap state page shows every task with its current status. The toy experiment has a dossier in both languages. The parity check (a check that the Polish and English versions say the same thing) passes on the generated pages.
