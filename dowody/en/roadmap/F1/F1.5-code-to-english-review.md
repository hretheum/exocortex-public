# F1.5. Translation folder by folder

[← F1](../F1-public-repo.md)

A serial task. The procedure is the same for every folder, and each item on the list is a separate atomic task.

## Procedure for one folder

1. Run the F1.4 tool on the folder.
2. Review the diff. Check that the translation keeps the meaning, and that proper names and terms match the glossary.
3. Run the tests.
4. Run language detection on the folder.
5. Commit with an English message, one per folder.

An item is ticked when language detection finds no Polish comments or messages and the tests pass.
