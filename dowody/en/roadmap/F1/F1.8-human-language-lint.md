# F1.8. Checking text for language model habits

[← F1](../F1-public-repo.md)

## Why

Many of the texts are written with help from language models and translated by a local model. Such texts have recognisable habits that tire the reader and weaken credibility. This check should catch them before publication so that a person can fix them.

## What to do

1. A list of patterns in both languages, in a configuration file, with a short reason next to each. Examples: filler phrases ("warto zauważyć", "kluczowy", "it's worth noting", "delve", "seamless"), openings like "Oto", wrap-ups like "Podsumowując", "it's not X, it's Y" constructions, rhetorical questions used as headings, bold in the middle of plain text, dense dashes used in place of commas, emoji.
2. Per-file measures: matches per 1000 words, density of bold and dashes, share of sentences starting with the same word.
3. Set thresholds on text written by people (for example a few of our own notes and documents), so that those pass.
4. The report shows the line and the pattern. Crossing a threshold blocks publication. An exception for a file needs an entry with a reason.

## Done when

The check passes on the human-written reference texts and on the current `dowody/` folder, and stops a prepared sample text full of these patterns.

## Notes

A clean result only means the text lacks the most obvious habits. Whether the text is good is for a person to judge.
