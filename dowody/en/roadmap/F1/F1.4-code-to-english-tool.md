# F1.4. Tool for translating comments and docstrings

[← F1](../F1-public-repo.md)

## Why

Part of the Exocortex code has comments, docstrings and messages in Polish. In the public repository code must be English only. Translating several hundred files by hand costs too much, and translating whole files with a model risks changing the code. We need a tool that touches only text.

## What to do

1. A Python script built on `libcst`, which preserves formatting. It extracts comments, docstrings, and strings passed to loggers, exceptions and command line help.
2. It detects the language of each fragment and translates only Polish ones, with a local model through llama-swap, using the F1.7 glossary.
3. It puts the translations back and checks that the syntax tree after the change, ignoring docstrings and comments, is identical to the tree before.
4. A separate mode for SQL files (`--` comments) and shell scripts (`#` comments).
5. The output is a diff ready for review, with no automatic commit.

## Done when

On three chosen modules the tool produces a diff in which only comments and strings changed, the syntax tree comparison passes, the tests pass, and language detection finds no Polish text in those modules.
