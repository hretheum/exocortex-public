# F0.2. List and check every public place

[← F0](../F0-leaks-and-gate.md)

## Why

F0.1 closes the known channels. There may be others: the project website, gists, release attachments, slides, recordings, posts with pieces of code or configuration. We need the full list to know what else to withdraw, and so that F0.3 gets the names that actually leaked somewhere.

## What to do

1. List every place where something from Exocortex was or is publicly available: package registries (all versions, not only the latest), the project site together with the repository it is built from, public repositories, release attachments, talk materials, posts.
2. Download the content of each place into a private working folder. Unpack images layer by layer.
3. Search the downloaded content with a preliminary list of names (before F0.3 exists) and with a simple search for email addresses and phone numbers.
4. For each place, record in a private report what is there, what breaks the rules and what was done.
5. Pass the names and fragments found on to F0.3.

## Done when

The private report covers every place on the list and each has a verdict ("clean" or "withdrawn" with a date). Publicly we record only that the audit took place and how many places it covered.

## Notes

The report is private because it contains what we are looking for. The working folder with downloaded content is deleted when F0.3 is finished.
