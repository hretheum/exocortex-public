# F0.1. Turn off public access to artifacts made before the rules

[← F0](../F0-leaks-and-gate.md)

## Why

The Exocortex container image in GHCR and the `exocortex-os` package on PyPI were created before the project rules were written down. The image was built from the whole repository folder and rebuilt on every push to `main`, so every new change in the repository became public straight away. We close this channel first and check the rest afterwards (F0.2).

## What to do

1. In the GitHub package settings, change the visibility of the `exocortex` and `exocortex-db` images to private. Check whether `postgres-age` also comes from this repository; if it does, do the same.
2. In the workflow that builds the images, turn off the step that pushes to the registry. Building can stay; publishing returns in F1.6.
3. On K12, log `podman` in to `ghcr.io` with a token that has `read:packages`. Without it, image updates on the server will stop working, because the packages will no longer be available anonymously.
4. On PyPI, delete release 0.1.0. Marking it as yanked is not enough, because the files can still be downloaded.
5. Record in the private log what was turned off and when.

## Done when

An unauthenticated request to the registry API returns an authorisation error for every tag of both images, the PyPI page shows neither release 0.1.0 nor files to download, the workflow has no publishing step, and `podman pull` on K12 works after logging in.

## Notes

Whatever has already been downloaded cannot be recalled. This task limits the damage from now on; F0.2 establishes what was visible and where.

## Progress

- 2026-09-27: step 1 done, the three image packages in GHCR are private and an anonymous request returns an authorisation error. Steps 2 to 5 are pending.
- 2026-09-28: step 3 done, `podman pull` on K12 works after logging in to GHCR. Step 4 done by the owner: release 0.1.0 deleted from PyPI. Step 2 was replaced by F1.6: images reach GHCR only after the gate scan, and all packages are private. Step 5 is pending.
